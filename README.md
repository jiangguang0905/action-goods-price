# 1 项目简介

本项目每日从京东联盟官方选品库接口获取在库商品的两个价格口径，写入SQLite，绘制近期走势并以内嵌图片发送邮件。取价全部来自官方授权接口，不依赖页面抓取、登录态Cookie或浏览器自动化。

## 1.1 价格口径

京东价取`priceInfo.price`，到手价取`purchasePriceInfo.purchasePrice`；两者口径不同，报表与走势图分别列示。

## 1.2 运行形态

本地以`run.bat`一键运行，云端由`.github/workflows/daily.yml`在`windows-latest`上每日北京时间10:23执行，两端共用同一份代码与`config.toml`。外部定时服务每日11:30触发兜底检查，当日无成功运行则补跑，并由心跳监控覆盖静默失败。

# 2 配置

## 2.1 非敏感配置

`config.toml`集中管理网关、邮件服务器、字体候选、商品名缩写规则、走势天数与重试参数。显示名由`[name]`段的正则与模板驱动，更换监测品类只改配置；`[report] days`决定走势窗口，标题、图片说明与横轴刻度自动适配。

## 2.2 私有环境变量

`JD_APPKEY`、`JD_SECRET`、`SMTP`、`MAIL_FROM`、`MAIL_TO`、`GROUP_ID`、`OWNER_UNION_ID`七项仅从环境变量读取：本地放在不入库的`.env`，云端由仓库`Secrets`注入。仓库内不含任何密钥、邮箱地址或账户编号明文。

# 3 本地运行

```text
建虚拟环境 → 安装requirements.txt → 填写.env → 运行run.bat
```

# 4 数据与校验

`price.db`按`spuid`与日期保存历史，每日由工作流回写仓库。取价请求具备超时与重试，配置、响应与商品字段均做校验，失败以非零退出码结束。`对接.md`列出每次更新后必须执行的同步校验清单。

# 5 声明

价格数据来自京东联盟官方接口，仅供个人参考，不构成购买或投资建议，不作商业用途，亦不代表京东官方背书。本仓库为公开仓库，运行日志同样公开，请勿在日志或提交中写入任何凭据与个人标识。
